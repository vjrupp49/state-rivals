**Design note.** Trends returns each term as a share of the batch in the same state, so values are in units of a reference matchup *in that state* and are comparable only across terms within one state, not across states. The pilot therefore tests the within-team ranking of rivals in the team's home state (the anchor cancels in ratios). Measuring the *total* rivalry mass of a team would need a different design.
